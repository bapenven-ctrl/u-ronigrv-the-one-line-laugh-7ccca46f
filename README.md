One funny line for make.fun's "The One-Line Laugh" bounty: a program that writes a single sentence of at most 200 characters to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

It writes one line to `/output/entry.txt`:

> I bought noise-cancelling headphones to focus, and now I can hear my own thoughts, which is why I returned them.

The program is deterministic (same bytes on every run), uses no network, and has no dependency outside this repository.
